# How to Run Django Experiment Locally

## 🚀 Quick Start

### **1. Navigate to Project Directory**
```bash
cd /path/to/purchase-of-info-omri
```

### **2. Activate Virtual Environment** (if using one)
```bash
# On Mac/Linux:
source bin/activate

# On Windows:
bin\activate
```

### **3. Install Dependencies** (if not already installed)
```bash
pip install -r requirements.txt
```

### **4. Run Database Migrations** (first time only)
```bash
python manage.py migrate
```

### **5. Start Development Server**
```bash
python manage.py runserver
```

### **6. Open in Browser**
```
http://localhost:8000
```

---

## 📋 Step-by-Step Guide

### **Prerequisites**
- Python 3.9+ installed
- All dependencies from `requirements.txt` installed

### **First Time Setup**

1. **Check Python version:**
   ```bash
   python --version
   # Should be 3.9 or higher
   ```

2. **Install dependencies:**
   ```bash
   pip install django pandas numpy requests
   # OR
   pip install -r requirements.txt
   ```

3. **Create database tables:**
   ```bash
   python manage.py migrate
   ```
   This creates `db.sqlite3` with all necessary tables.

4. **Verify CSV file exists:**
   ```bash
   ls data/conditions_experiment_3ps_11x11_120_A.csv
   ```
   Should show the file exists.

### **Running the Server**

1. **Start server:**
   ```bash
   python manage.py runserver
   ```

2. **You should see:**
   ```
   Starting development server at http://127.0.0.1:8000/
   Quit the server with CONTROL-C.
   ```

3. **Open browser:**
   - Go to: `http://localhost:8000` or `http://127.0.0.1:8000`
   - You should see the landing page!

### **Stopping the Server**

Press `Ctrl+C` in the terminal where the server is running.

## 🔍 Troubleshooting

### **Port Already in Use**
If you see "Port 8000 is already in use":
```bash
# Use a different port:
python manage.py runserver 8001
# Then open: http://localhost:8001
```

### **Module Not Found Errors**
```bash
# Make sure you're in the project directory
pwd
# Should show: .../purchase-of-info-omri

# Reinstall dependencies
pip install -r requirements.txt
```

### **Database Errors**
```bash
# Delete old database and recreate:
rm db.sqlite3
python manage.py migrate
```

### **CSV File Not Found**
```bash
# Check file exists:
ls -la data/conditions_experiment_3ps_11x11_120_A.csv

# If missing, copy it from the data folder
```

## 🧪 Testing the Experiment

### **Complete Flow Test:**

1. **Landing Page** (`http://localhost:8000`)
   - Should show welcome message
   - Click "Start Experiment"

2. **Consent Form**
   - Read consent
   - Click "Begin the Experiment"

3. **reCAPTCHA** (if enabled)
   - Complete reCAPTCHA
   - Or skip if disabled in code

4. **Instructions**
   - Click through instruction screens
   - Should see 6 screens total

5. **Block 1** (10 trials, no DS)
   - Should see trial counter: "1/10", "2/10", etc.
   - No DS recommendation shown
   - Make decisions, see feedback

6. **Block 2** (10 trials, with DS)
   - Should see DS recommendation (red/green)
   - Make decisions

7. **Block 3** (100 trials, with DS)
   - Should see trial counter: "1/100", "2/100", etc.
   - DS recommendations shown
   - Complete all 100 trials

8. **TOAST Questionnaire**
   - Answer questions about system trust

9. **End Page**
   - Thank you message

### **Check Database:**

```bash
# View database contents (optional):
python manage.py shell
>>> from experiment.models import ExperimentData, ExperimentAction
>>> ExperimentData.objects.count()  # Number of participants
>>> ExperimentAction.objects.count()  # Number of trial responses
>>> exit()
```

## 💡 Understanding Django

### **What is Django?**
Django is a Python web framework that handles:
- **URL routing**: Maps URLs to functions (`urls.py`)
- **Views**: Functions that handle requests (`views.py`)
- **Templates**: HTML pages with dynamic content (`templates/`)
- **Models**: Database structure (`models.py`)
- **Admin**: Built-in admin interface

### **Request Flow:**
```
User clicks link
    ↓
URL matches pattern in urls.py
    ↓
Calls function in views.py
    ↓
Function processes request
    ↓
Renders HTML template
    ↓
Sends HTML to browser
```

### **Key Files:**
- **`manage.py`**: Django management script
- **`settings.py`**: Configuration
- **`urls.py`**: URL routing
- **`views.py`**: Backend logic
- **`models.py`**: Database models
- **`templates/`**: HTML files
- **`static/`**: CSS, images, JavaScript

## 🚨 Important Notes

1. **Don't close the terminal** while server is running
2. **Changes to Python files** require server restart (Ctrl+C, then restart)
3. **Changes to HTML/CSS** just need browser refresh
4. **Database** (`db.sqlite3`) stores all participant data
5. **CSV files** in `data/` are outputs, not inputs (except the conditions CSV)

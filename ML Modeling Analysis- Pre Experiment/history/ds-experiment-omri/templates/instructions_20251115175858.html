Instructions

Machine Reading: The module's condition is represented by a number. The higher the number, the more likely an intervention is needed.

Decision Making: Since the number represents the probability that the module needs an intervention, the threshold for an intervention might change from module to module.

Block 1: You will now need to classify 10 events, each referring to a specific car module. Decide whether the module needs an intervention based on the provided number (stimulus).

Welcome to the Experiment

Role: Assume that you are a engineer in an autonomous-vehicle factory.

Your Task: You will monitor autonomous vehicle modules and decide whether a module needs to be inspected manually or not.

Please read each instruction screen carefully. When you're ready, click "Next" to proceed to the next screen.

{% elif screen == 2 %}

Instructions

Machine Output: Each module shows a number indicating the probability it needs inspection. Higher numbers = more likely to need intervention.

Block 1 (Practice - 10 trials): You will see only the machine output number. Use this number alone to decide whether the module needs an intervention based on the provided Machine Output number.

{% elif screen == 3 %}

Scoring System

You start with 30 points. After each decision, you'll see if you were correct or incorrect and your score will be updated accordingly:

  • Correctly identify intervention needed: +{{ v_tp }} point | Miss it: -{{ v_fn }} points

  • Correctly identify no intervention needed: +{{ v_tn }} points | False alarm: -{{ v_fp }} points

{% elif screen == 4 %}

Block 2 (Practice - 10 trials with DS)

What's Different: Now you'll see both the machine output number AND a Decision Support (DS) system recommendation.

DS System: The system shows a colored rectangle:

  • Red rectangle = "Alarm" (system recommends intervention)

  • Green rectangle = "No Alarm" (system says no intervention needed)

Important: The DS system is not perfect - it can make mistakes. Be aware of its output and use your judgment to decide whether to follow its recommendation or not.

{% elif screen == 5 %}

Ready for Block 2

Now you will start another 10 trials practice block. In each trial you will see in the machine output number and the DS system's output as a colored rectangle (red = Alarm, green = No Alarm).

Remember: The DS system can be wrong. Make your own decision based on *all* available information.

Scoring works the same as Block 1 - you'll get feedback after each decision.



{% elif screen == 6 %}

Block 3 (Main Experiment - 100 trials)

What's Different: This is the main experiment block with 100 trials. Everything works the same as Block 2:

  • You'll see the machine output number

  • You'll see the DS system recommendation (red/green rectangle)

  • You decide: intervention needed or not

  • You get feedback and points after each decision

Your score resets to 30 points for this block. The scoring rules remain the same.
